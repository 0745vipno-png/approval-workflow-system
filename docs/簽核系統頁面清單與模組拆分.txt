一、整體模組架構

| 模組代碼 | 模組名稱         | 說明               |
| ---- | ------------ | ---------------- |
| M1   | 驗證與帳號模組      | 登入、登出、個人資料、密碼修改  |
| M2   | Dashboard 模組 | 依角色顯示首頁摘要資訊      |
| M3   | 申請單模組        | 建立、編輯、送出、查看申請單   |
| M4   | 簽核處理模組       | 主管 / HR 的審核與處理   |
| M5   | 進度與通知模組      | 簽核進度、簽核歷程、通知中心   |
| M6   | 查詢與報表模組      | 條件查詢、歷史案件、報表     |
| M7   | 系統管理模組       | 使用者、部門、主管關聯、角色設定 |

這樣切的好處是：

前後端都容易對應
畫面不會散掉
後續資料表與 API 命名也容易一致

三、共用頁面與共用元件

有些頁面其實所有角色都會共用，只是內容不同。

| 頁面          | 共用角色 | 說明            |
| ----------- | ---- | ------------- |
| 登入頁         | 全部   | 系統入口          |
| Dashboard   | 全部   | 內容依角色不同       |
| 通知中心        | 全部   | 顯示不同通知        |
| 個人資料頁       | 全部   | 查看帳號資訊        |
| 密碼修改頁       | 全部   | 基本帳號管理        |
| 申請詳情 / 簽核詳情 | 多角色  | 同一頁可依角色顯示不同按鈕 |


共用元件

側邊欄 Sidebar
頂部導覽列 Navbar
狀態標籤 Status Badge
清單表格 Data Table
搜尋條件列 Filter Bar
詳情卡片 Detail Card
簽核進度條 Stepper
歷程時間軸 Timeline
確認視窗 Modal
通知卡片 Notification Item
