四、條件權限說明（很重要）
1. 🔒 僅限本人資料

例如申請人查看申請單：

只能看 applicant_id = 自己帳號 的資料

前端要過濾，後端 API 也要驗證。

2. 🔁 有條件允許

例如撤回申請：

允許條件：

狀態 = Pending
主管尚未簽核
申請人本人操作
if status == Pending && not approved_by_manager
3. 👁️ 僅可查看

例如 Admin 看待簽核案件：

可以查詢
不能代替簽核

六、實作建議（前後端）
前端 React / Vue

登入後取得：

{
  "userId": "A001",
  "roles": ["Requester", "Manager"]
}

根據 roles 決定：

顯示哪些頁面
顯示哪些按鈕
顯示哪些清單
後端 API

即使前端隱藏按鈕，也一定要驗證：

POST /approve/:id

檢查：

是否為主管角色
是否為當前簽核人
狀態是否可簽核
七、進階建議（加分用）
一人多角色

Requester

超級管理員
